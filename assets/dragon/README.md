# Cethiel’s Dragon 3D

Authors: Drummyfish and Cethiel. License: CC0-1.0.
Source: https://opengameart.org/content/cethiels-dragon-3d
License text: https://creativecommons.org/publicdomain/zero/1.0/legalcode

The source page explicitly dedicates the model and animations to CC0. Original archive is preserved as cethiel-dragon-cc0.zip; manifest.json pins its SHA-256. Run tools/convert_dragon.py with NumPy and Pillow to reproduce the generated Luau geometry, rig and clips. Runtime uses EditableMesh and requires enabling Mesh / Image APIs for the experience. No Dark Souls assets are included.
