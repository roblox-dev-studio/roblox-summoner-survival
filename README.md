# 소환사 서바이벌 · Roblox Summoner Survival

마법과 소환수로 몰려오는 적을 상대하며 **2분 생존 후 드래곤 보스를 처치하는 Roblox 게임 프로토타입**입니다. 직접 이동하고 대시하면서, 경험치를 모아 새로운 마법을 배우거나 능력을 강화합니다.

## 시작하기

1. 이 저장소를 ZIP으로 내려받거나 복제합니다.
2. Roblox Studio에서 **새 Baseplate 프로젝트**를 엽니다.
3. Studio의 **Command Bar**를 엽니다. 재생 전 편집 상태에서 실행해야 합니다.
4. [install.luau](install.luau)를 텍스트 편집기로 열고 전체 내용을 Command Bar에 붙여 넣어 실행합니다.
5. 설치 완료 메시지를 확인하고 프로젝트를 저장한 뒤 **▶ Play**를 누릅니다. 로비에서 자동 마법 4개를 선택하고 **전투 시작**을 누릅니다.

설치기는 전장, 서버·클라이언트 스크립트, 통신 이벤트를 생성합니다. 같은 이름의 기존 객체가 있으면 중단하므로 **빈 프로젝트에서 시작하세요**. GitHub 코드를 받아 Studio에서 실행하는 방식이며, Roblox에 배포된 게임 링크는 아직 포함하지 않습니다.

새 드래곤 표시는 **EditableMesh**를 사용합니다. 게임 소유자가 본인 인증 후 **File → Experience Settings → Security → Allow Mesh / Image APIs**를 켜야 합니다. 미설정 시 클라이언트 Output에 DragonMesh 오류가 나오며 드래곤 외형이 표시되지 않습니다. 드래곤 데이터는 설치기에 포함되고 별도 이미지 업로드는 필요하지 않습니다.

현재 패턴 확인을 위해 시작 체력을 **150**으로 설정했습니다. 재시작에도 적용됩니다. 기본 체력 조정은 `src/server/flow/Session.luau`의 `STARTING_HEALTH`에서 합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 우클릭 드래그 / 휠 | 카메라 회전 / 확대·축소 |
| 좌클릭 / F / 게임패드 R1 | 누르고 있으면 캐릭터 정면으로 기본 마법탄 연속 발사 |
| Q / 게임패드 R2 | 로비에서 선택한 사용 스킬을 캐릭터 정면으로 발동 · 재사용 대기시간 7초 |
| E / 게임패드 B | 이동 방향으로 대시 · 재사용 대기시간 3초 |
| 드래곤 보기 버튼 / V | Studio에서 전투를 멈추고 드래곤 외형·모션 확인 |
| 스킬 미리보기 버튼 / P | Studio에서 마법·Q·골렘·대시 이펙트 확인 |
| 레벨업 카드 클릭 | 선택한 마법·골렘 또는 생존 능력 강화 |

캐릭터를 원하는 쪽으로 이동시켜 몸을 돌린 뒤 공격합니다. Q는 캐릭터 정면으로 나가며 마우스 위치나 카메라 회전으로 조준하지 않습니다. 방향 화살표는 표시하지 않습니다. 선택한 Q 스킬과 대시는 화면 버튼으로도 사용할 수 있습니다. 기본 마법과 소환수 공격은 자동입니다. Space로 점프합니다.
R15 이동·점프·착지에 기존 테스트에서 가져온 CC0 하체 모션을 혼합합니다.
사망 전용 모션은 아직 추가하지 않았습니다. 혼자 플레이할 때는 레벨업 선택 중 전투가 멈춥니다.

## 강화 상태로 보스전만 테스트하기

Studio Play의 로비에서 자동 마법4개와 Q를 선택한 뒤 **보스전 테스트 · 스킬5단계**를 누르세요. 선택한 자동 마법과 골렘이5단계(표시 레벨21)가 되고 일반 몹 구간 없이 드래곤이 바로 등장합니다. 보스 체력은 일반전의2배(솔로5,760)로 늘려 패턴을 더 오래 볼 수 있습니다. Q는 기존 고정 성능이며 플레이어 체력은150을 유지합니다. 친구와 테스트할 때는 모두 같은 테스트 모드로 준비해야 합니다. 개발용 버튼/서버 요청은 Studio에서만 허용됩니다.

도전 중단 또는 패배 후 로비로 돌아와 **전투 시작**을 누르면 원래1단계 생존전으로 돌아옵니다. 조합/Q 선택만 유지되며 테스트 강화는 저장되지 않습니다.

꼬리 공격은 드래곤의30스터드 이내 후방(정면과 내적−.35 미만)에 있을 때 우선 선택합니다. 드래곤이 먼저 플레이어를 향해 돌아서지 않고, 제자리에서 예고 후 꼬리를 휘두르며 플레이어가 있던 방향을 바라봅니다. 한 바퀴 도는 고정 순환 패턴에서 제외했고 꼬리 반격은8초 간격으로 제한합니다.

## 몹 미리보기

Studio Play 로비의 **몹 미리보기 [N]** 버튼 또는 **N**으로 엽니다. 잿빛 해골 병사·쌍검 해골 도적·철갑 해골 집행자·황혼 해골 마도사·불씨 폭탄 운반꾼·잿불 뿔사냥개6종의 실전 모델과 특징을 볼 수 있습니다. 아래 버튼으로 **대기/이동/공격 시연**, **일반/정예**, **일시정지**, **시점 초기화**를 선택하고 드래그/휠로 회전·확대합니다. 패드는 목록 선택/오른쪽 스틱 회전/L1·R1 확대·축소/B 닫기를 지원합니다.

행동 시연은 로컬 공간에서 경로 예고·마법탄·폭발 범위를 보여주며 피해를 주지 않습니다. 실제 적 AI/전투 판정을 재현하는 테스트는 아닙니다. 열려 있는 동안 Studio 전투가 멈추고, 스킬/드래곤 미리보기와는 한 번에 하나만 열립니다. 닫으면 원래 로비/전투로 돌아갑니다.

## 드래곤 모습만 확인하기

Studio에서 Play 후 **왼쪽 위 ‘드래곤 보기 [V]’**를 누르세요. 별도 화면에서 드래그로 회전하고 휠로 확대/축소할 수 있습니다. 기본 모습·걷기·비행·꼬리 공격과 정면/측면·자동회전·일시정지를 선택할 수 있습니다. 하단 **닫기** 또는 **V**로 돌아옵니다. 사망 후에도 볼 수 있습니다.

이 버튼은 개발용으로 Studio에서만 표시됩니다. 열어 둔 동안 서버 전투·타이머가 멈추고 이동/공격 입력이 잠깁니다. Studio 협동 테스트에서는 다른 참가자의 전투도 함께 멈춥니다. 실제 캐릭터나 전투 드래곤의 위치를 바꾸지 않습니다.

## 구현된 요소

- 독립적으로 적을 찾아 이동하는 골렘과 밀집한 적을 노리는 자동 대지 강타.
- Q 화염탄: 캐릭터 정면으로 한 발을 쏘며 첫 충돌 지점 반경 5에 피해 75를 줍니다. 속도 58·사거리 42·대기시간 7초, 벽에 막힙니다. 회전하는 불꽃과 긴 꼬리, 짧은 잔향을 유지합니다. 자동 화염탄은 Q로 이동했고 화염 파동은 개선 전까지 선택/미리보기에서 제외했습니다.
- 흰 중심·푸른 잔광의 줄기가 하늘에서 내려꽂히고 가지·지면 방전·짧은 재섬광으로 이어지는 연쇄 번개. 착탄부는 굵은 두 전류와 청백색·보라색 오라, 바깥으로 퍼지는 충격 고리로 강조합니다.
- 공중 마법진에서 발사되는 얼음창, 적중 시 밀치기·빙결·둔화.
- 높이 약 76스터드에서 3.2초 동안 천천히 내려오는 대형 메테오: 암석 외피·용암 균열·화염 꼬리·충격파·파편·그을음, 1단계 폭발 반경 15.
- 비전 결정: 등 뒤에 둥근 빛 5개를 부채꼴로 띄우고 .18초 간격으로 각각 발사한 뒤 다시 충전. 가까운 여러 적을 나눠 추적하며 각 탄환은 한 명만 타격. 서리 폭발: 냉기 응축 후 다중 충격파·얼음 결정·냉기 안개와 광역 빙결. 수호 결계: 체력보다 먼저 피해를 흡수하는 보호막.
- 천공의 창: 상공의 이중 마법진에서 긴 마법 창 5자루가 차례로 낙하하며 좁은 경로를 관통. 접근하는 일반 적의 이동을 예상해 조준합니다.
- 전장 밖 마법사의 안식처와 시작 전 스킬 셋 선택. 중력 구체는 선택/성장 목록에서 제외했습니다.
- 5단계까지 성장하는 마법·골렘과 체력·이동 속도·경험치 수집 범위 강화.
- 기본 18스터드 경험치 자동 흡입, 자석 강화당 범위 +3, 레벨업 선택지, 승리·패배와 재시작. 끌려오기 시작한 구슬은 범위를 벗어나도 따라옵니다.
- 흑염룡 아그니스: 20% 확대된 CC0 메시·이동에 맞춘 걸음·넓게 펼치는 날갯짓·돌진 기울기, 광역 브레스·공중 화염 쓸기·비행 돌진·화염 지대 폭발·회전 꼬리·지상/공중 십자 화염·공중 원형 화염·착지 내려찍기, 범위 예고·체력바·2단계·처치 승리.
- 일반 적 6종: 추적자, 측면으로 파고드는 거미, 느리고 튼튼한 갑각수, 옆으로 이동하는 마도사, 폭발형, 주황색 경로 예고 후 직선 돌진하는 붉은 뿔짐승. 후반에는 금빛 표식의 정예도 등장.

현재는 **골렘 효과 확인 모드**가 켜져 있습니다. 1단계에서도 5단계의 외형 효과를 보여주지만 피해량은 실제 단계 기준입니다. 단계별 연출을 사용하려면 [Combat.luau](src/server/combat/Combat.luau)의 `PREVIEW_MAX_GOLEM_EFFECTS`를 `false`로 바꾸세요.

협동용 서버 처리와 경험치 공유의 기반은 있지만 여러 클라이언트를 사용하는 협동 플레이와 모바일 기기 검증은 아직 하지 않았습니다. 장기 저장과 완성된 진화 시스템은 미구현입니다.

보스 체력과 전투 타이머는 오른쪽 위, 플레이어 체력·레벨·경험치·스킬·골렘 상태는 왼쪽 아래에 표시합니다. 공격·대시 버튼은 오른쪽 아래에 있습니다.

기획 문서는 향후 개발 제안이며 현재 구현 목록과 구분합니다. 드래곤은 전투 시작 120초 뒤 등장하며 보스전에는 제한 시간이 없습니다. 남은 일반 적은 경험치 구슬을 남기고 사라지며 보스전에는 일반 적이 추가로 나오지 않습니다. 보스를 처치하면 승리하며 플레이어가 쓰러지면 패배합니다. 개발용 외형 시연 코드는 `models/warden_preview.server.luau`에 보관합니다.

소스 수정 후 Python 3으로 설치기를 다시 생성합니다.

```sh
python3 tools/build_installer.py
python3 tools/check.py
```

검사 도구는 처음 한 번 `python3 tools/bootstrap_luau.py`로 준비합니다.
설치기는 각 진입점 아래 `Modules` 폴더와 ModuleScript를 함께 만듭니다.
**진입점 두 개만 복사하면 실행되지 않습니다.** 기존 단일 스크립트 버전에서 전환할 때는
새 Baseplate에 갱신된 `install.luau` 전체를 설치하세요. 기존 place를 자동 덮어쓰지 않습니다.

## 함께 개발하기

버그와 아이디어는 Issues에, 변경 제안은 Pull Request에 올려 주세요. [CONTRIBUTING.md](CONTRIBUTING.md)에 참여 방법이 있습니다.

Roblox 내장 텍스처와 Creator Store의 바위 메시를 사용합니다. 바위 메시를 불러오지 못해도 기본 파편 효과로 동작합니다. 제3자 소재의 이용 조건은 [ASSET_CREDITS.md](ASSET_CREDITS.md)에 기재되어 있습니다. 프로젝트 코드의 별도 오픈소스 라이선스는 아직 지정하지 않았습니다.

일반 적은 최대 84마리이며 18초마다 양쪽에서 6마리의 추가 무리가 들어옵니다. 65초 이후 9번째 생성 개체마다 체력 1.75배·크기 1.2배·경험치 3개인 정예가 섞입니다. 일반 적은 0초부터 추적자, 12초부터 거미, 28초부터 갑각수, 32초부터 돌진형, 42초부터 마도사, 60초부터 폭발형이 섞입니다. 마도사는 준비 후 보라색 탄환을 쏘고, 폭발형은 붉은 원에서 벗어나거나 폭발 전에 처치하면 대응할 수 있습니다. 드래곤은 솔로 체력 2880이며 체력 절반부터 폭발 지점이 3→5개, 폭발 반경이 12→14로 늘고 브레스 폭과 공격 빈도가 증가합니다. 폭발에는 확산 충격파·다중 불꽃 기둥·불씨·그을음 연출이 함께 나옵니다.

## 로비와 스킬 셋

Play하면 마법사의 안식처에서 시작합니다. 얼음창·연쇄 번개·메테오·비전 결정·서리 폭발·수호 결계·추적 마탄·천공의 창·성운 광륜 중 **서로 다른 자동 마법 4개**를 고르세요. 이미 선택한 카드를 눌러 해제한 뒤 다른 카드를 선택합니다. 기본 조합은 얼음창 + 메테오 + 비전 결정 + 성운 광륜입니다.

전투 시작을 누르면 선택한 마법은 모두 1단계로 시작합니다. Q 사용 스킬은 화염탄·뇌창·성운창·빙하 쇄도 중 하나를 별도로 선택합니다. 대시와 골렘은 공통으로 제공합니다. 레벨업 선택지는 장착한 네 마법과 골렘의 5단계 강화, 필요 시 생존 강화로 구성됩니다. 다른 마법을 쓰려면 종료 후 로비로 돌아와 조합을 바꾸세요. 중력 구체는 제외했습니다.

친구와 같은 서버에 있으면 모두 준비해야 함께 출발합니다. 준비를 취소할 수 있으며, 진행 중 참가자는 로비에서 다음 전투를 기다립니다. 전투 종료 화면의 **로비로 돌아가기**는 전원이 종료된 후 라운드를 초기화합니다. 스킬 셋은 같은 접속 중 다음 라운드에도 유지되며 영구 저장은 아직 없습니다. 실제 다중 클라이언트·기기 검증은 남아 있습니다.

메테오·서리 폭발은 지상 적을 대상으로 합니다. 비전 결정은 48스터드 안의 가까운 적 최대 5명을 나눠 겨냥해 속도 48로 추적 발사합니다. 5발을 소진하면 1단계 4.05초 동안 충전합니다. 각 탄환은 첫 적 한 명만 타격하며 범위 피해는 없습니다. 보스는 서리 피해·둔화는 받지만 빙결되지 않습니다. 수호 결계는 일반 몹·원거리 탄환·보스 공격을 흡수하며 초과 피해는 체력에 들어갑니다. 결계 외형은 화면의 캐릭터 위치에 매 프레임 붙어 이동합니다.

Q 네 기술은 모두 캐릭터 정면을 사용합니다. 화염탄은 정면으로 이동하다 첫 적/벽 충돌 때 반경 5에 피해 75를 주며, 뇌창은 0.4초 준비 뒤 속도48/비행거리52로 정면 발사되는 번개 창이며, 실제 3D 경로의 적을 한 번씩 관통하고 벽에 막힙니다. 빙하 쇄도는 길이 34/반폭 6의 지상 냉기 파동과 일반 적 빙결입니다. 빙하 쇄도는 0.4초 준비 뒤 가까운 곳부터 0.075초 간격으로 7열을 솟게 하고 각 열이 솟을 때 적마다 한 번만 피해를 주며 뇌창도 날아가서 적에 닿아야 피해를 줍니다. 메뉴 중에는 준비와 비행 시간도 멈춥니다. 로비 복귀 시 Q 선택도 같은 접속 중 유지됩니다.

## 스킬 이펙트 미리보기

Studio Play에서 로비의 **스킬 미리보기** 버튼(전투 시작 옆) 또는 **P**를 누르세요. 전투 중에는 왼쪽 버튼으로도 열 수 있습니다. 왼쪽 목록에서 자동 마법 9종, Q 4종, 골렘 대지 강타와 대시를 선택합니다. 실제 게임과 같은 이펙트를 별도의 로컬 공간에서 재생하며 피해·XP·장착은 바꾸지 않습니다.

드래그로 회전하고 휠로 확대/축소합니다. 하단에서 **다시 재생**, **반복 켬/끔**, **단계 1·3·5**, **시점 초기화**, **닫기**를 사용할 수 있습니다. Q와 대시는 공통 외형, 골렘은 현재 게임 설정과 같은 최대 단계 외형을 보여줍니다. 패드는 목록/버튼 선택, 오른쪽 스틱 회전, L1/R1 줌, B 닫기를 연결했으며 실제 하드웨어 검증은 남아 있습니다.

개발용으로 Studio에서만 표시됩니다. 보는 동안 서버 전투·타이머가 멈추며 Studio 협동 테스트에서는 전원에게 적용됩니다. 닫으면 원래 로비 또는 전투 화면과 카메라로 돌아갑니다. 드래곤 보기와는 서로 닫고 전환됩니다.

추적 마탄은 단일 대상 집중 공격용 자동 주문입니다. 58스터드 안의 보스를 가장 먼저, 그다음 체력이 높은 적을 노립니다. 1단계2발~5단계4발이며 적을 추적하다가 한 대상에만 피해를 주고 사라집니다. 폭발 범위 피해는 없으며 비행 중 대상이 죽으면 다른 적을 찾습니다. 스킬 셋과 미리보기에서 선택할 수 있습니다.

시작 카메라는 캐릭터 뒤 24·위 14스터드, FOV 70의 일반 3인칭으로 초기화합니다. 초기화 후 기본 카메라에 제어를 넘기며 확대 범위는 8~85입니다. 미리보기 종료 시 기존 전투 시점도 복구합니다. 뇌창은 입체 창날·금색 날개 장식·이중 전류 고리·움직이는 번개·불꽃 입자를 사용합니다.

뇌창 외형은 끝에서 끝까지 약 24스터드이며 17스터드의 가는 금속 창대·금빛 마디/문양·길고 뾰족한 입체 창날을 사용합니다. 천공의 창은 자동 마법 슬롯에서 고르고, 스킬 미리보기에서도 확인할 수 있습니다.

성운창은 뇌창과 별도로 고르는 Q 스킬입니다. 부드러운 청색/보라색 잔광이 모여 가는 빛의 창을 형성합니다. 기존 뇌창의 금속 창대·금색 장식·전류 고리는 유지하며, 현재 두 창은 준비 .4초·속도48·사거리52·쿨다운7초의 관통 판정을 공유합니다. 비전 결정은 네모난 결정 면과 탄환 날개를 제거하고 둥근 발광체5개로 표시하며, 중앙 빛이 머리에 가려지지 않게 높이와 간격을 조정했습니다.

성운창의 피격 판정은 이펙트 크기와 별도로 가로 반폭4.8(전체 폭9.6)입니다. 위아래 허용 범위는 기존2.4로 유지하며 뇌창은 기존 가로 반폭2.4입니다.

## 빛 스킬과 기본 공격

- 성운 광륜: 가까운 지상 적을 향해 지면과 평행하게 누운 보랏빛 초승달이 곡선을 그리며 38스터드까지 나갔다가 플레이어에게 돌아옵니다. 적마다 갈 때/올 때 각1회 관통 피해를 줍니다. 수평 회전이 서서히 빨라지고 양 끝에 짧은 빛 꼬리와 잔광을 남깁니다.
- 빙하 쇄도: 기존 피해·정면 범위·빙결을 유지하고 큰 얼음 기둥7개와 옆 얼음 결정7개가 지면에서 순차적으로 솟고, 내부 발광·모서리 빛·생성 섬광·냉기 입자·주변 서리와 작은 얼음 파편으로 연출합니다.
- 기본 공격: 좌클릭/F/패드R1 또는 오른쪽 아래 마법탄 버튼을 누르고 발사합니다. 지금은 별빛 지팡이1종으로 .3초 간격·피해13·속도80·거리52이며 첫 적만 타격합니다. 무기별 수치는 서버 combat/Weapons, 발사/판정은 BasicAttack, 이펙트는 클라이언트 LightArt에 분리했습니다. 무기 획득/장착 UI와 근접 무기는 아직 구현하지 않았습니다.

자동 마법은 10종 중4개를 선택하며 Q1종·기본 공격·대시·골렘은 별도입니다. 레벨업 선택지는 기존처럼 카드3개를 제시합니다. 새 주문과 기본 공격도 스킬 미리보기에서 확인할 수 있습니다.


전투 중 오른쪽 위 **도전 중단 · 로비**를 누르면 스킬 선택창으로 돌아갑니다. 선택한 마법4개와 Q는 유지하며 레벨·체력·쿨다운은 초기화합니다. 협동에서는 본인만 복귀하고 친구의 전투는 계속됩니다. 마지막 전투 참가자가 복귀하면 라운드 전체를 초기화합니다. 패배 화면의 로비 버튼도 같은 방식으로 동작합니다.

## 해골 병사 외형

기본 근접 적(stalker)은 KayKit CC0 해골 병사 모델로 표시합니다. 투구·붉은 망토와 원본 대기/걷기/주먹 공격 모션을 실전과 몹 미리보기[N]에 함께 적용했습니다. 정예는1.2배/금빛 표식이며 기존 능력치는 유지합니다. 드래곤과 같은 Mesh/Image API 설정을 사용하고, 생성에 실패하면 기존 간단한 적 외형이 남습니다. 출처와 재변환 방법은 [해골 에셋 안내](assets/enemies/kaykit-skeletons/README.md)를 참고하세요.

정예 해골 병사는 검·방패를 들고 원본 한손 내려치기 모션을 사용합니다. 도적은 쌍검과 빠른 달리기, 집행자는1.3배 큰 중갑 몸체와 도끼·대형 방패, 마도사는 모자·지팡이와 준비/시전, 운반꾼은 폭탄·도화선을 사용합니다. 사냥개는 네 다리·턱·긴 꼬리가 움직입니다. 모두 실전과 N 미리보기에 같은 외형/장비를 표시하며 기존 출현 시점·피해·체력·경험치는 유지합니다. 미리보기에서 일반/정예를 바꿔 비교할 수 있습니다.

몹의 걸음은 개체마다 시작 위상과 템포(±6%)가 다르고, 이동 중 작은 좌우 흔들림을 부드럽게 적용합니다. 위치 갱신 사이의 걷기/대기 깜빡임을 줄였고, 정지·빙결 중에는 흔들림이 가라앉거나 멈춥니다. 판정용 위치와 공격 시각은 기존 서버 기준입니다. 중간 필드보스는 [해골 군단장 구상](docs/FIELD_BOSS_DESIGN.md)으로 정리했으며 아직 구현하지 않았습니다.

## 중간 필드보스 · 망령 기마 군단장

일반 생존60초에 등장하는 해골 기마 보스입니다. 도끼창 횡베기·내려찍기·전진 찌르기·군마 돌진을 서로 다른 주황색 바닥 예고로 알립니다. 공격 뒤에는0.8초 빈틈이 있습니다. 상시 접촉 피해는 없고 빙결/넉백 대신 둔화만 받습니다.

살아 있는 참가자 모두에게 강화 선택1회와 최대 체력20% 회복을 줍니다. 기존 선택창이 열렸으면 다음 선택으로 이어집니다. 처치가 곧 최종 승리는 아니며105초까지 살아 있으면 보상 없이 퇴각하고120초 드래곤은 기존대로 등장합니다. 군단장이 있는 동안 새 잡몹과 추가 무리의 압박을 줄입니다.

Studio 로비 **필드보스 테스트 · 스킬3단계**로 바로 확인하세요. 선택한 네 마법과 골렘3단계로 시작하며, **드래곤 테스트 · 스킬5단계**에는 군단장이 나오지 않습니다. 군단장 기수는 금빛 닫힌 투구·겹 어깨 갑옷·남색 장식깃을 가진 전용 절차 모델이며 방패 없이 긴 양손 도끼창을 사용합니다. 실제 다인 난이도와 최종 미술은 추가 조정이 필요합니다.

군단장의 이동 속도는15, 돌진은30스터드를0.5초에 이동합니다. 횡베기 준비0.75초/돌진 준비0.8초, 공격 후 회복0.8초이며 솔로 체력은1,560입니다.
