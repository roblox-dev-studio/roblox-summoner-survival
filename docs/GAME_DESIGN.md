# 소환수 수집형 마법 서바이벌 — 게임 방향 검토안

> 작성일: 2026-10-18
> 목적: 실제로 만든 전투를 바탕으로 준비·전투·영구 성장의 역할을 다시 정한다.
> 상태: 논의 중인 검토안. 구현 범위나 최종 사양을 확정하는 문서가 아니다. 현재 구현 목록은 README.md를 기준으로 한다.
> **합의**는 이번 대화에서 채택한 방향, **초안**은 구현·플레이 테스트로 조정할 제안이다. 수치 예시는 출시 확정값이 아니다.

## 1. 게임의 핵심

**소환수와 장비를 준비하고, 직접 마법을 사용하며 몰려오는 적을 상대하고, 전투 중 얻는 마법으로 조합을 완성해 보스를 쓰러뜨리는 액션 서바이벌 게임.**

플레이어는 몰려오는 적의 공격을 피하며 살아남아야 한다. 이동·기본 공격·Q·대시를 직접 조작하고, 소환수와 자동 마법은 독립적으로 전투를 돕는다. 혼자 또는 친구들과 함께 도전한다.

재미의 중심은 다음 세 가지다.

- **조작:** 공격할 방향과 타이밍을 고르고, 적의 예고를 읽어 피한다.
- **한 판의 조합:** 무작위 선택지를 보고 새 마법을 배우거나 가진 마법과 Q를 강화한다.
- **지속되는 성장:** 보상으로 소환수와 장비를 키우고 새 선택지를 얻어 다음 도전을 준비한다.

영구 강화만으로 모든 전투가 해결되거나, 소환수가 혼자 전부 처리하는 상태는 목표가 아니다. 직접 조작과 이번 판의 마법 선택이 끝까지 중요해야 한다.

## 2. 현재 논의한 방향

| 항목 | 방향 | 상태 |
| --- | --- | --- |
| 출전 준비 | 소환수 1종, Q 1종, 무기·방어구·장신구 선택 | 합의한 기본 방향 |
| 자동 마법 | 입장 후 레벨업 선택으로 습득. 보유 개수 상한은 진행하며 결정 | 습득 방식은 기본 방향, 상한은 미정 |
| Q 성장 | 전투 중 레벨업 선택지에 Q 강화 포함 | 합의 |
| 소환수 성장 | 로비에서 코인으로 영구 강화, 레벨업 카드에서 제외 | 합의 |
| 장비 성장 | 로비에서 코인으로 영구 강화 | 합의 |
| 스킬 해금 | 플레이 보상·과제로 해금하고, 이번 판 습득과 구분 | 기본안 |
| 스테이지 | 일반 전투 → 필드보스 → 최종 보스 | 기본안 |
| 한 판 길이 | 일반적인 클리어 기준 8~10분 목표, 보스전 시간 제한 없음 | 테스트 초안 |
| 저항과 약점 | 소수의 속성 저항과 보스별 특수 상호작용 | 기본안, 상세 미정 |
| 소환수 획득 | 기본 제공·클리어 보상·플레이로 얻는 소환권 | 기본안, 상세 미정 |

이 문서에는 별도 확률 보정이나 누적 횟수에 따른 확정 획득 체계를 설계하지 않는다. 카드·소환 확률과 강화 비용은 전투 구조를 검증한 뒤 정한다.

## 3. 전체 플레이 흐름

**로비 → 스테이지 정보 확인 → 소환수·장비·Q 준비 → 전투 → 경험치와 마법 성장 → 필드보스 → 최종 보스 → 보상 정산 → 영구 강화·새 획득 → 재도전.**

로비에서는 선택한 소환수와 장비의 특징, Q 동작을 미리 확인할 수 있다. 스테이지 화면은 주요 적, 보스의 공격 속성, 간단한 공략 힌트, 보상을 보여준다.

전투 중에는 적을 처치하고 경험치를 얻는다. 레벨업하면 제시된 카드 중 하나를 골라 마법을 배운다. 적 구성이 달라지고 필드보스를 거치면서 빌드를 완성한 뒤 최종 보스에 도전한다.

최종 보스를 처치하면 승리한다. 솔로에서 쓰러지거나 협동에서 더 이상 생존자가 없으면 패배한다. 언제든 도전을 중단하고 로비로 돌아갈 수 있다.

## 4. 출전 준비와 조작

### 4.1 출전 구성

| 슬롯 | 개수 | 역할 |
| --- | --- | --- |
| 소환수 | 1 | 독립 행동과 고유 기술, 플레이어와의 연계 |
| 무기 | 1 | 기본 공격의 형태와 전투 스타일 |
| 방어구 | 1 | 체력·방어·저항 중심의 생존 선택 |
| 장신구 | 1 | 특별한 조건부 효과 또는 특정 플레이 보조 |
| Q | 1 | 직접 조준하고 사용하는 핵심 마법 |
| 자동 마법 | 미정 | 입장 시 미보유, 전투 중 습득. 4개 이상 보유도 검토 |

무기는 사용할 Q나 자동 마법의 속성을 제한하지 않는다. 특정 무기를 들었다고 해금한 마법을 사용할 수 없게 하지 않는다.

### 4.2 직접 하는 행동

- 이동으로 적의 공격과 포위를 피한다.
- 기본 공격은 누르고 있으면 반복하며 무기에 따라 형태가 달라진다.
- Q는 캐릭터가 바라보는 방향을 기준으로 사용한다. 카메라 회전과 공격 방향의 관계를 일관되게 안내한다.
- 대시는 위치를 바꾸고 위험을 벗어나는 수단이다. 무적 여부·시간은 별도 조작 테스트로 결정한다.
- 기본 공격과 Q, 대시의 게임패드 조작을 유지한다. 모바일은 버튼 배치와 조준 방식을 따로 검증한다.

장시간 준비 동작으로 움직임을 불필요하게 막지 않는다. 기술별로 발사 시점·방향 고정 시점·이동 가능 여부가 명확해야 한다.

## 5. 스테이지와 한 판의 길이

지역별 스테이지를 기본으로 한다. 첫 지역은 현재 만든 왕성 광장과 해골 계열 몹, 망령 기마 군단장, 드래곤을 활용한다. 다른 지역은 첫 지역의 전투 흐름을 검증한 뒤 추가한다.

아래는 **8~10분 클리어를 목표로 한 예시**다. 강제 종료 시간표가 아니다.

| 구간 | 예상 시점 | 경험 |
| --- | --- | --- |
| 도입 | 0~2분 | 기본 공격·Q·소환수로 시작, 첫 자동 마법 습득 |
| 확장 | 2~4분 | 다른 역할의 적 등장, 자동 마법 조합 형성 |
| 필드보스 | 4분 전후 | 군단장의 돌진·무기 공격을 공략 |
| 고조 | 필드보스 이후 | 정예와 혼합 무리, 주요 마법 강화 |
| 최종 보스 | 6~7분 전후 진입 목표 | 드래곤의 패턴을 읽으며 완성한 조합 사용 |

필드보스가 살아 있는 동안 최종 보스를 겹쳐 등장시키지 않는 것을 첫 기본안으로 둔다. 필드보스전에는 잡몹을 제한적으로 유지하고, 최종 보스 진입 시 일반 몹 생성은 멈추는 안부터 테스트한다.

긴 보스전 때문에 시간 초과로 패배하지 않는다. 반복 플레이에서 지루한 대기 구간이 생기면 단순히 몹 체력을 늘리지 말고 구간 길이와 적 조합을 조정한다.

## 6. 경험치와 전투 중 성장

### 6.1 경험치 획득

첫 적용은 현재의 **경험치 구슬과 주변 자동 흡입 방식**을 활용한다. 적이 죽으면 구슬이 나오고, 가까이 가면 끌려온다. 소환수·자동 마법·Q·기본 공격 중 무엇으로 처치해도 보상에 차이를 두지 않는다.

협동에서는 구슬을 누가 주웠는지와 관계없이 해당 전투의 참가자가 같은 경험치를 받는 안을 기본으로 한다. 마지막 타격이나 수집 경쟁이 성장 차이를 만들지 않게 한다. 로비에 있거나 전투에서 이탈한 플레이어는 공유 대상이 아니다.

기존 문서의 ‘즉시 70% + 구슬 30%’ 방식은 이번 기본안에 포함하지 않는다. 구슬 획득의 재미와 이동 부담을 먼저 실제 전투에서 확인한다.

### 6.2 레벨업 카드

레벨업마다 **무작위 카드 3개 중 1개 선택**을 초기안으로 한다.

| 카드 유형 | 내용 | 등장 조건 |
| --- | --- | --- |
| 새 자동 마법 | 해금한 마법을 이번 판에 습득 | 아직 배우지 않은 마법. 보유 개수 제한 여부는 추후 결정 |
| 자동 마법 강화 | 이미 배운 마법의 성능·동작 개선 | 해당 마법 보유, 최대 단계 미만 |
| Q 강화 | 선택한 Q의 성능·동작 개선 | 최대 단계 미만 |

소환수·무기·방어구의 강화 카드는 넣지 않는다. 자석·회복 등 보조 효과를 전투 중 선택지에 포함할지는 검토한다. 현재 단계에서 제외하거나 필수로 넣는 것으로 확정하지 않는다.

자동 마법의 보유 개수 상한은 아직 정하지 않는다. 현재 테스트의 4개 구성을 최종 규칙으로 사용하지 않으며, 더 많은 마법을 함께 사용할 때의 조합·가독성·성능을 확인하며 결정한다. 같은 선택 화면에 동일 카드를 중복 표시하지 않으며, 최대 단계 강화 카드도 제외한다. 더 이상 유효한 카드가 없을 때의 선택창과 경험치 처리는 보조 효과 포함 여부 및 성장 속도 테스트 후 정한다.

전투 중 배운 자동 마법 교체는 첫 버전에 넣지 않는다. 카드에 역할과 다음 강화 효과를 보여줘 선택 전에 판단할 수 있게 한다.

### 보조 효과 카드 검토

다음은 채택 여부를 판단할 후보이며 확정된 카드 목록이 아니다.

| 후보 | 가능한 형태 | 확인할 점 |
| --- | --- | --- |
| 자석 | 이번 판 경험치 흡입 범위 증가 또는 주변 구슬 즉시 회수 | 기본 흡입만으로 충분한지, 이동 부담을 줄이는 선택으로 가치가 있는지 |
| 회복 | 즉시 체력 회복 또는 이번 판 지속 회복 | 위기에서 회복과 공격 성장을 맞바꾸는 선택이 재미있는지 |
| 기타 생존·편의 | 최대 체력·이동 속도 등 이번 판 효과 | 장비의 역할과 지나치게 겹치거나 필수 선택이 되지 않는지 |

자석의 범위 강화와 일회성 구슬 회수, 즉시 회복과 지속 회복은 서로 다른 효과로 평가한다. 레벨업 카드로 제공할지, 필드 획득물로 제공할지도 비교한다. 채택한다면 최대 체력 상태의 즉시 회복처럼 효용이 없는 선택의 등장 조건과 강화 상한을 정한다. 전투 중 얻은 보조 효과는 영구 장비 강화와 구분한다.

### 6.3 성장 속도

첫 레벨업은 시작 후 약 20~30초를 목표로 테스트한다. 시작부터 기본 공격·Q·소환수가 있어야 자동 마법을 얻기 전에도 행동할 수 있다.

자동 마법은 습득을 포함해 5단계, Q는 기본 1단계에서 최대 5단계까지 성장하는 안으로 시작한다. 한 판의 선택 횟수는 자동 마법 보유 수와 보조 카드 포함 여부를 함께 보며 조정한다. 새로운 마법을 여럿 배우는 선택과 일부 마법을 집중 강화하는 선택이 모두 의미가 있는지, 보스 진입 시 주요 기술을 충분히 키울 수 있는지 확인한다.

### 6.4 선택 중 시간

솔로는 선택 중 전투를 멈추는 안을 유지한다. 협동은 동일한 공유 경험치로 함께 레벨업하고 전원이 선택하면 재개하는 안부터 검증한다. 선택 제한시간·미선택 처리·이탈 처리는 다인 테스트 전에 확정한다. 다른 사람의 선택이 반복해서 긴 대기가 되는지 확인한다.

## 7. 마법 해금과 스킬 구성

**계정 해금**은 앞으로 해당 마법을 사용할 자격을 얻는 것이고, **이번 판 습득**은 레벨업 카드로 실제 전투 슬롯에 넣는 것이다.

처음에는 Q와 자동 마법을 각각 여러 종류 기본 제공해 시작부터 선택이 가능하게 한다. 추가 마법은 스테이지 첫 클리어·보스 처치·특정 도전 과제로 해금한다. 마법 자체를 소환수와 함께 뽑기 상품으로 묶지 않는다.

검증용 버전에서는 모든 마법을 해금한 채 카드 선택 구조부터 테스트한다. 해금 순서는 재미와 조작 난도를 확인한 다음 정한다.

### 7.1 직접 사용하는 Q 후보

| 마법 | 역할 | 강화 예시 — 아직 미구현 설계 |
| --- | --- | --- |
| 화염탄 | 빠른 투사체로 정면 적 타격 | 위력·피격 폭 증가, 적중 시 작은 폭발 |
| 빙하 쇄도 | 순차적인 얼음 결정 공격으로 경로 압박 | 결정 수·범위 증가, 둔화 보강 |
| 뇌창 | 긴 창 형태의 관통 공격 | 관통 경로 확대, 적중 전기 방출 |
| 성운창 | 얇고 빠른 마력 창 | 위력·유효 폭 증가, 짧은 추가 타격 |
| 천광 포격 | 준비 후 넓은 직선 광선 | 준비시간 단축, 위력·폭 증가 |

Q 강화는 피해량 증가뿐 아니라 사용감도 바꾸되, 매 단계 이펙트를 과도하게 키우지 않는다. 재사용 대기시간 감소에는 최종 하한을 두어 준비·회피·공격의 구분을 유지한다. 정확한 수치는 기술별 테스트에서 결정한다.

### 7.2 자동 마법 후보

| 역할 | 후보 | 주는 선택 |
| --- | --- | --- |
| 직선·관통 | 빙결 얼음창 | 줄지어 접근하는 적 대응 |
| 분산 타격 | 연쇄 번개 | 흩어진 적과 가까운 무리 처리 |
| 강한 지연 공격 | 메테오 | 큰 적·밀집 지역에 집중 피해 |
| 개별 추적 | 비전 결정 | 등 뒤 결정이 각각 목표로 발사 |
| 왕복 경로 공격 | 성운 광륜 | 초승달 투사체의 왕복 경로 활용 |
| 지점 공격 | 천공의 창 | 위에서 순차 낙하하는 마법 창 |
| 생존 지원 | 수호결계 | 접근 위협을 견디는 보조 |

목록은 현재 자산을 활용할 후보이며 모두 같은 역할로 늘리지 않는다. 화염 파동과 소용돌이는 첫 구성에서 제외한 상태로 둔다. 같은 기술을 Q와 자동 슬롯 양쪽에 중복 장착시키는 규칙은 초기에는 넣지 않는다.

## 8. 소환수: 획득과 영구 강화

출전 소환수는 1마리다. 플레이어를 따라다니되 스스로 적을 탐색하고 자신의 기본 공격과 특수 기술을 사용한다. 소환수가 적을 추격하느라 멀리 남거나 지형에 갇히지 않도록 복귀 규칙을 둔다.

| 소환수 | 기본 성격 | 처음부터 가능한 핵심 행동 | 영구 성장 예시 |
| --- | --- | --- | --- |
| 골렘 | 가까운 무리를 상대하는 묵직한 전투 지원 | 독립 이동·근접 공격·자동 대지 강타 | 위력·강타 범위·공격 효율 개선 |
| 폭풍 까마귀 | 비행하며 주요 적을 노리는 공격 지원 | 깃털 발사·급강하·Q와 연계하는 낙인 | 추가 깃털·복귀 공격·낙인 연쇄 효과 |

핵심 기술을 장기간 강화 뒤에만 사용할 수 있게 하지 않는다. 높은 단계는 원래의 특징을 발전시키는 역할이다. 기존 전투 중 단계별 효과는 영구 강화의 단계 보상으로 재배치할 수 있으나, 비용과 해금 단계는 별도로 조정한다.

로비에서 코인을 사용해 확정 강화한다. 강화 실패나 별도 강화 재료는 첫 버전에 넣지 않는다. 공격력 등 기본 성장은 완만하게 올리고, 특정 단계에서 기술의 변화를 보여준다. 성장 분기는 이후 확장 후보다.

골렘을 기본 제공하고, 초반 클리어 보상으로 다른 소환수 1종을 얻는 안으로 시작한다. 이후 플레이 보상으로 얻은 소환권으로 추가 소환수를 획득한다. 뽑기 확률·중복 획득 처리·유료 판매는 아직 결정하지 않았으며 실제 뽑기 기능 구현 전에 정한다.

소환수 외형은 적합한 공개 모델과 원본 애니메이션을 우선 조사한다. 출처·제작자·라이선스를 기록하고 게임 내 표시 의무도 따른다. 공개 자료라는 이유만으로 자유 사용이 가능한 것으로 취급하지 않는다.

## 9. 장비: 역할과 강화

### 9.1 세 가지 슬롯

- **무기:** 기본 공격과 전투 스타일을 결정한다.
- **방어구:** 기본 생존 능력과 저항을 제공한다.
- **장신구:** 특정 행동을 보조하는 고유 효과를 제공한다.

지팡이는 정면 마력탄, 마도서는 유도 파편, 마법 검은 가까운 검격 같은 방식으로 구별한다. 이는 후보이며 첫 검증에는 무기 한 종류로 시스템을 연결해도 된다.

장비는 스테이지·보스 보상 또는 상점으로 얻는다. 코인 강화는 기본 성능을 높이고, 다른 장비 획득은 공격 방식이나 고유 효과의 선택을 넓힌다. 초기 장비는 고정된 특징을 사용하며 무작위 부가 옵션은 넣지 않는다. 희귀도별 수치와 종류 수는 추후 정한다.

### 9.2 교체와 투자 회수

새 소환수·장비를 얻었을 때 이전 강화 비용 때문에 사용을 포기하지 않게 한다. **강화 초기화 시 투자 코인을 전액 반환하는 방식**을 첫 초안으로 둔다. 초기화는 로비에서만 가능하고, 영구 강화 단계만 되돌린다. 획득한 소환수나 장비 자체는 유지한다. 중복 비용 반환이 생기지 않게 서버에서 처리한다.

### 9.3 능력치

| 능력치 | 의미 |
| --- | --- |
| 최대 체력 | 견딜 수 있는 총 피해 |
| 방어력 | 기본 피해 경감; 첫 버전은 모든 직접 피해에 적용하는 안 |
| 화염·냉기·번개 저항 | 해당 속성 피해의 추가 감소 |
| 이동 속도 | 위치 선정과 회피의 기동성 |
| 재사용 대기시간 감소 | 스킬 사용 간격 단축, 최종 하한 필요 |
| 고유 효과 | 대시 후 보호막 등 조건이 명확한 특별 효과 |

물리 피해에는 기본 방어력을 적용하고, 별도 물리 저항 수치는 우선 만들지 않는다. 방어력과 속성 저항의 중첩 계산식·상한은 구현 전에 통일한다. 저항을 모아 무적이 되거나 피해가 음수가 되지 않도록 한다.

냉기 피해 감소와 빙결 지속시간 감소는 다른 효과다. 상태 이상 저항은 초기에는 일부 장비의 고유 효과로만 다루고 모든 상태에 별도 수치를 만들지 않는다.

## 10. 적·필드보스·최종 보스

### 10.1 일반 적의 역할

| 역할 | 첫 지역에서 활용할 적 | 요구하는 대응 |
| --- | --- | --- |
| 기본 추적 | 해골 병사 | 이동하며 적 수를 줄이기 |
| 빠른 접근 | 도적·사냥개 | 옆과 뒤를 확인하고 빠르게 대응 |
| 중장갑 압박 | 집행자 | 강한 공격을 집중하거나 우회 |
| 원거리 방해 | 마도사 | 투사체를 피하고 우선 처치 |
| 지역 위험 | 폭탄 운반꾼 | 접근 전에 제거하거나 폭발 범위 이탈 |

난이도는 체력과 공격력뿐 아니라 적의 비율·접근 방향·원거리와 근거리의 조합으로 올린다. 정예는 크기·무기·색상 등으로 구분하고 강화된 행동을 알아볼 수 있게 한다. 외형과 모션이 동시에 똑같이 반복되지 않도록 보행 위상과 움직임을 자연스럽게 분산한다.

### 10.2 망령 기마 군단장

돌진만 반복하지 않고 접근·대검 휘두르기·넓은 횡베기·재정렬을 섞는다. 범위와 준비 동작을 읽고 피할 수 있어야 한다. 빠른 행동과 짧은 휴식 사이에도 공격할 틈은 남긴다. 갑옷을 입은 해골 기사와 해골 군마라는 외형을 유지한다.

### 10.3 드래곤

지상 숨결·돌진·비행 공격·착지 강타·후방 꼬리 공격을 위치와 거리별로 사용한다. 꼬리 공격은 뒤에 있는 플레이어를 견제하고 정면으로 돌기 위한 행동으로 활용한다. 날개·다리·꼬리 동작이 이동과 공격 타이밍에 연결되어야 한다.

### 10.4 저항과 특수 약점

첫 보스부터 복잡한 속성 상성표를 요구하지 않는다. 보스별 특수 상호작용 하나를 먼저 검증한다.

예: 드래곤이 숨결을 준비할 때 냉기 공격을 일정량 맞으면 열기가 줄고 숨결 범위가 작아진다. 발동 가능 상태와 성공 결과를 화면에서 구별할 수 있어야 한다. 반복 적용으로 보스를 영구 봉쇄하지 않게 한다.

이 예시는 **아직 채택·구현하지 않은 테스트 후보**다. 특정 속성이 없어도 회피와 공격으로 공략할 수 있어야 한다. 보스 저항 때문에 화염 중심 조합 등이 사실상 무효가 되지 않도록 한다. 플레이어의 저항 장비는 실수의 부담을 낮추는 준비 수단이지 입장 필수 조건이 아니다.

## 11. 협동 플레이

목표는 1~4인 협동이다. 경험치는 함께 받고, 마법 선택·소환수·장비는 각자 정한다. 서로 다른 역할의 소환수와 마법을 가져오는 재미를 살린다.

인원 증가에 맞춰 적 수와 보스 체력을 조정하되, 공격력을 단순히 인원수만큼 늘리지 않는다. 좁은 곳에 공격 예고가 겹쳐 회피 불가능해지는지 따로 확인한다.

협동에서 쓰러진 플레이어를 일정 시간 내 구조하는 방식은 후속 설계 대상이다. 구조 시간·횟수·보스전 적용 여부는 확정 전이다. 전투 중 신규 참가 허용 여부도 별도로 정하며, 첫 구현은 로비에서 함께 준비해 시작하는 흐름을 우선한다.

다른 플레이어의 이펙트는 중요도를 낮출 수 있어야 한다. 적의 공격 예고와 자신의 Q 방향이 소환수·자동 마법 효과에 가려지지 않게 한다.

## 12. 보상과 반복 플레이

초기 재화는 **코인과 소환권** 두 종류를 중심으로 한다. 코인은 소환수·장비 강화와 상점에 사용하고, 소환권은 소환수 획득에 사용한다. 용도가 없는 재료를 미리 늘리지 않는다.

| 활동 | 보상 방향 |
| --- | --- |
| 일반 전투·필드보스 | 진행 중 코인 획득 |
| 최종 보스 클리어 | 추가 코인과 장비 보상 |
| 스테이지 첫 클리어 | 마법 해금 또는 정해진 특별 보상 |
| 일일 접속·간단한 일일 과제 | 소량의 코인·소환권 |

패배·자발적 중단 시에도 이미 획득한 보상은 유지하고, 최종 클리어 보상은 성공한 경우에만 준다는 안으로 시작한다. 같은 라운드 보상을 재접속·중복 요청으로 여러 번 받지 않도록 한다. 연결 종료 시 미정산 보상을 어떻게 복구할지는 저장 설계에 포함한다.

일일 활동은 평소 전투를 하면서 완료할 수 있게 한다. 출석하지 않은 날 때문에 기존 성장을 잃게 하지 않는다. 가격·획득량·소환 확률은 현재 문서에서 확정하지 않는다.

## 13. 화면과 시각적 방향

로비에서 스테이지·소환수·Q·장비·강화 메뉴를 구분한다. 출전 요약에는 현재 선택과 주요 능력치를 한눈에 보여준다. 소환수·마법·적 미리보기는 유지한다.

전투에서는 보스 정보를 오른쪽 위, 자신의 체력·경험치·상태를 왼쪽 아래에 둔다. Q 재사용 시간과 사용할 수 있는 상태를 명확히 표시한다. 자동 마법은 작은 아이콘과 단계로 확인할 수 있게 한다.

레벨업 카드는 이름·역할·현재 단계·선택 후 변화가 중심이다. Q 강화와 자동 마법 습득을 쉽게 구분한다. 획득 불가능한 카드나 최대 단계 카드는 표시하지 않는다.

효과는 빛과 움직임으로 특징을 살리되 공격 모양과 판정이 맞아야 한다. 화면 전체를 가리는 잔광, 지나간 자리에 오래 남는 장식, 정지된 그림처럼 보이는 투사체는 줄인다. 보스 공격의 예고는 장식보다 우선한다.

## 14. 현재 프로토타입과 목표 설계의 차이

아래는 전환 작업을 위한 구분이며 구현 완료 선언이 아니다.

| 항목 | 현재 프로토타입 | 이번 목표 |
| --- | --- | --- |
| 자동 마법 | 입장 전 4개 선택 | 빈 슬롯으로 입장, 전투 중 습득 |
| Q | 로비 선택, 고정 성능 중심 | 레벨업 카드로 이번 판 강화 |
| 소환수 | 골렘/까마귀 선택, 전투 중 단계 강화 | 코인 영구 강화, 전투 카드에서 제거 |
| 기본 공격 | 공통 마법탄 | 장착 무기별 동작 |
| 장비 | 영구 장비 체계 없음 | 무기·방어구·장신구와 강화 |
| 전투 길이 | 짧은 개발용 진행, 드래곤 120초 등장 | 지역별 8~10분 목표 진행 검증 |
| 계정 성장 | 장기 저장·획득 체계 미완성 | 소유·강화·재화·해금 저장 |
| 협동 | 기반 구현, 실제 다인 검증 필요 | 경험치·선택·보상·이탈까지 검증 |

기존 소스와 모델은 활용한다. 문서를 작성했다고 Studio나 실제 게임 동작을 자동 변경하지 않는다.

## 15. 개발 순서와 완료 기준

### 단계 A — 한 판의 마법 선택

자동 슬롯을 비우고 시작하도록 변경한다. 새 자동 마법 습득·강화·Q 강화 카드를 연결하고, 소환수 카드를 제거한다. 검증 중에는 모든 마법 해금과 고정된 시험용 소환수 성능을 사용한다.

완료 기준: 첫 마법을 얻기 전에도 할 일이 있고, 매 판 같은 선택만 하지 않으며, Q와 자동 마법 중 무엇을 강화할지 의미 있는 고민이 생긴다. 선택 가능한 카드가 사라졌을 때도 진행이 멈추지 않는다.

### 단계 B — 영구 성장의 최소 연결

코인·소환수 강화·소유 장비·장비 강화를 저장한다. 최소 장비부터 연결하고 투자 초기화·보상 정산을 구현한다. 뽑기 UI보다 보상과 저장의 일관성을 먼저 검증한다.

완료 기준: 재접속해도 보유·강화 상태가 일치하고, 중단·패배·승리 보상이 규칙대로 반영된다. 중복 지급이나 코인 음수가 발생하지 않는다.

### 단계 C — 첫 지역 한 판 완성

몹 구성과 필드보스·드래곤의 흐름을 목표 시간에 맞춘다. 장비와 Q 준비, 전투 중 선택이 보스 공략에 영향을 주는지 확인한다. 속성 상호작용은 하나씩 추가한다.

완료 기준: 영구 강화가 낮아도 조작으로 개선할 여지가 있고, 높은 강화에서도 모든 패턴을 무시할 수는 없다. 적의 공격이 읽히고 공략할 틈이 있다.

### 단계 D — 수집과 협동 확장

소환권·소환수 추가 획득·중복 처리·해금 순서·일일 보상을 연결한다. 실제 다인과 모바일·게임패드를 검증하고, 이후 지역과 장비 종류를 늘린다.

## 16. 구현 전에 남겨둔 결정

- 소환수 중복 획득 처리, 실제 확률과 소환권 지급량.
- 강화 단계 상한·비용 곡선·장비 희귀도, 투자 초기화 UX.
- 방어력·속성 저항 계산식과 상한, Q 재사용 시간 하한.
- 협동 선택 제한시간·쓰러짐과 구조·전투 중 합류 규칙.
- 자동 마법 보유 개수 상한의 필요성과 적정 개수, 스킬별 강화 효과 및 교체 기능의 필요성.
- 자석·회복 등 보조 카드의 포함 여부, 즉시 효과와 이번 판 지속 효과의 구분 및 등장 조건.
- 모든 성장 완료 후 경험치 처리, 긴 보스전의 회복 수단.

이 항목들은 현 단계의 게임 방향을 다시 정할 이유가 아니라, 해당 기능 구현 전에 확정해야 할 세부 사항이다.

## 17. 테스트에서 확인할 질문

1. 자동 마법이 없는 시작 구간에도 기본 공격·Q·소환수로 충분히 재미있는가?
2. Q 강화가 자동 마법 습득·강화와 경쟁할 만큼 매력적인가?
3. 마법을 더 배우는 선택과 가진 마법을 강화하는 선택이 모두 매력적인가? 보유 수가 늘어도 전투가 읽히는가?
   자석·회복 카드를 추가하면 선택이 풍부해지는가, 원하는 마법의 등장을 방해하는가?
4. 소환수의 개성이 처음부터 느껴지고, 강화 후 변화도 알아볼 수 있는가?
5. 새 소환수·장비를 얻었을 때 실제로 바꿔 써보고 싶은가?
6. 패배 원인이 공격을 피하지 못한 것인지, 성장 수치 부족인지 플레이어가 이해하는가?
7. 일반 전투와 필드보스가 최종 보스에 가기 위한 지루한 대기로 느껴지지 않는가?
8. 협동에서 선택 대기와 이펙트가 흐름을 방해하지 않는가?

완주 시간·사망 구간·마법 선택률·Q 사용 횟수·보스 진입 단계·중단 시점을 함께 기록한다. 수치만으로 재미를 단정하지 않고 실제 플레이 소감과 비교한다.
