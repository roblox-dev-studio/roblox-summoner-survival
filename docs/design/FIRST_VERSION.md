# 마법 서바이벌 — 첫 버전 한 장 기획

**2026-10-16 · 팀 검토 초안 · 기준 구현 `ab247ef`**  
방향: 3D 뱀파이어 서바이벌형 자동전투 + 마법 + 증강 + 클래스. **소환수는 후속 버전**으로 미룬다. 저장소 이름은 유지한다. 아래 목표는 구현 완료 목록이 아니다.

## 플레이 약속

**“피해서 살아남고, 마법을 골라 조합하고, 마지막에는 처음과 다른 방식으로 적 무리를 쓸어버린다.”**
직접 조작은 이동·대시·위기 탈출용 스킬에 집중한다. 조준과 기본 공격은 자동이다. 반복 플레이의 이유는 다른 증강 조합, 클래스 숙련, 외형 수집이다.

## 첫 판과 조합

입장 → 바로 전투 → 처치/경험치 → 증강 선택 → 조합 변화 → 3분 결과 → 다른 선택으로 재도전.
첫 선택은 **얼음 습득 / 번개 습득 / 화염 강화**를 보장한다. 한 판에 5~7회 선택을 목표로 튜닝한다.
불 집중은 넓은 폭발, 불+얼음은 얼린 적을 깨뜨리는 **열충격**, 얼음+번개는 얼린 적을 연결하는 **빙결 전도**를 지향한다. 두 조합 증강은 신규 구현이며 한 판에 하나만 선택한다.

## 완료 기준과 순서

| 단계 | 납품 결과 | 통과 기준 |
| --- | --- | --- |
| M0 방향 전환 | 골렘 없는 기본 전투·HUD·선택지 | 자동 전투/레벨업/사망/재시작 회귀 통과 |
| M1 마법·증강 | 위 세 빌드와 증강 12개 | 선택 전후 공격/이동 전략 차이를 실제 플레이로 확인 |
| M2 첫 3분 | 튜토리얼, 적 2행동, 결과/재도전 | 비개발자 5명 중 4명이 도움 없이 첫 선택; 이탈 이유 기록 |
| M3 클래스 | 3클래스·해금·저장 기반 | 동일 스탯에서 플레이 방식이 달라지고 선택/저장 복구 정상 |
| M4 수집 | 무료 가챠·희귀도·도감·확정 제작 | 보상/중복/천장/재접속이 일치하고 전투 성능 판매 없음 |
| M5~M6 출시 판단 | 모바일·저장 안정성·행동 지표·소규모 외부 테스트 | 치명 오류 해소, 실제 반복 플레이 근거 확인 후 공개 승인 |

**현재:** 자동 전투·레벨업·재시작 및 R15 하체 모션 솔로 검증 완료. 클래스/조합 전용 증강/저장/수집/가챠/튜토리얼은 미구현. 골렘은 아직 코드에 있어 M0에서 기본 루프와 분리해야 한다.

**팀 운영:** 전투·마법 / 적·월드 / 성장·사용자 흐름의 세 기능 영역으로 분담하되 담당은 이슈마다 정한다. PM은 범위·우선순위·검수 기준을 관리한다. 마일스톤 통과 전 다음 단계의 대규모 제작을 시작하지 않는다.
