## 다음 작업의 순서와 완료 기준

1. **성장 손실 제거 — 이번 변경.** 구슬180개를 유지하면서1002 XP 보존, 팀 공유1회, 연속 레벨 카드와 잔여 XP 보존. 실제 엔진 fixture와 일반 전투 흐름을 분리해 기록합니다.
2. **첫 판의 안내.** 새 계정이 메뉴 설명을 읽지 않아도 첫 성장 선택까지 도달해야 합니다. 안내는 실제 행동 완료로 넘어가며 전투를 강제로 조작하거나 가짜 보상을 주지 않습니다.
3. **빌드 완성의 보상.** 먼저 기존 마법 한 조합의 진화 후보를 정하고, 조건 충족·선택·공격 변화·표시·판 종료 초기화를 검수합니다. 마법 슬롯 정책은 팀 논의와 함께 확정합니다.
4. **한 판의 밀도.** 첫 카드까지 걸린 시간, 보스 도달 레벨, 선택 횟수, 사망 원인을 기록해 수치를 조정합니다. 현재120초 프로토타입을 근거 없이 장기 스테이지 길이로 늘리지 않습니다.
5. **반복 플레이와 출시 기반.** 결과 화면의 다음 목표와 한 종류의 영구 해금부터 저장/재접속을 검증합니다. 상점·가챠·소환수 확장과 별개로 협동·모바일 검수는 첫 공개 전에 완료합니다.

각 작업은 작은 PR로 규칙·구현·검수·이미지를 함께 전달합니다. 완료한 변경만 구현 상태에 올리고,
새 의사결정은 기획 검토에 남깁니다. 유료 상품 생성이나 게임 공개는 이 보강 작업에 포함하지 않습니다.
