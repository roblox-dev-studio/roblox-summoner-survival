# 변경분 Studio 인수 체크리스트

현재 동작은 README.md / ARCHITECTURE.md의 최종 통합 상태를 기준으로 합니다. 검사 시 커밋/작업 트리, 설치기, Studio ID, 기기와 클라이언트 수를 PLAYTEST_NOTES.md에 기록합니다. 엔진 fixture는 실제 다중 클라이언트나 사람의 미적/난이도 평가를 대신하지 않습니다.

## 설치와 기본 회귀

- 새 빈 Baseplate의 편집 모드에 생성된 install.luau 전체 설치. 기존 place 재설치 금지. 서버/클라이언트 진입점과 src 모듈 수·내용 확인.
- Play: 로비/HUD, 서버/클라이언트 Output 오류, 카메라 기본3인칭, 적 생성/이동·골렘 공격 확인.
- 자동 마법 아홉 종류 중 서로 다른 네 개 선택. 세 개/다섯 개/중복/희소 배열/퇴역 ID 거부. 기본은 얼음창/메테오/비전 결정/성운 광륜.
- 장착 마법만1단계로 출발, 경험치 흡입/레벨업 카드3개/강화·정지·재개, 비장착 마법 제외.
- 대시 쿨다운/이동 복구/벽, 체력·보스 HUD 위치, 사망/승리/재출발 초기화.

## 기본 공격과 Q

- 좌클릭/F/R1/화면 버튼 홀드·해제·포커스 이탈·화면 밖 해제. Q/대시 병행과 메뉴/사망 중 차단. 서버 연사 제한, 캐릭터 정면, 실제 비행·첫 적 단일 피해·벽·정리.
- Q 옵션 화염탄/뇌창/성운창/빙하 쇄도. Q/R2/화면 버튼, 반복 입력 쿨다운, 정면 발사·벽·취소·정지·복귀 후 선택 유지. 화염 파동은 선택/갤러리에서 제외.
- 화염탄: 속도58/거리42, 첫 충돌의 반경5 피해75, 공중/수직·측면 범위 제한, 사망/복귀 정리. 밝기/중심과 붉은 외곽의 균형, 회전과 긴 불꽃 꼬리, .14초 잔광/.16초 이하 잔불. 고정 바닥 불길 없음.
- 뇌창/성운창: .4초 준비 뒤 실제 비행/관통, 성운창만 넓어진 수평 판정. 빙하: 가까운 순서7열/한 번 피해/일반 적 빙결·밀치기/보스 면역.

## 자동 마법과 시각

- 광륜: 지표면과 평행한 초승달·가속 회전·빛 꼬리·곡선 왕복, 출발/귀환 각1회 타격, 벽·선택 정지·정리.
- 결계: 이동/점프 중 캐릭터에 즉시 붙음, 갤러리 앵커 고정, 흡수/파괴/초과 체력 피해.
- 빙하:7열 순차 성장/지면 섬광/주변 서리·파편/초승달 없음/정리.
- 번개: 상공 흰 중심·푸른 코로나/하단 전류/착탄 오라/바깥으로 확산하는 청·보라 고리/정리.
- 메테오: 천천히 낙하하는 큰 운석/예고/실제 피해/메뉴 중 정지. 비전 결정5개 개별 추적/충전, 천공의 창5개 낙하, 서리 빙결/보스 면역, 마탄 단일 추적/벽.
- 갤러리: 자동9종/Q4종/기본 공격/골렘/대시, 공통 기술 단계 잠금, 반복/재생/회전/줌·복귀, 같은 렌더러와 전투 정지/재개, 중복 효과/연결 없음.

## 로비 복귀와 협동

- 전투/레벨업 선택/패배에서 로비 복귀. 네 자동 마법/Q 보존, 레벨/체력/쿨다운 초기화, 재출발. 오래된 상태/중복 요청/추가 인자 거부.
- 실제 Server & Clients2명: 모두 준비/취소·미준비 이탈·중간 참가, 개인 선택 정지, 본인만 복귀·다른 사람 계속 전투, 마지막 참가자 복귀 시 전체 초기화.
- 보스 등장/일반 몹 정리/시간 제한 없는 공략, 패턴 예고/회피/처치 승리. 임시 BossSpawnAt 등의 테스트 속성을 제거.
- 모바일/패드 실제 기기: 이동/카메라/터치 홀드·해제/Q/E/카드/화면 겹침. 최대 예상 적/이펙트 수에서 프레임·서버 부담 측정.

## 재현 가능한 fixture

Server: studio_basic_attack, studio_light_spells, studio_active_spells, studio_lobby, studio_retreat. Client: studio_ward_follow, studio_glacial_art, studio_elemental_art. 기존 studio_area_spells / studio_homing_missiles / studio_boss_combat / studio_enemies도 변경 영역에 따라 실행합니다. fixture 실행은 본인 임시 객체만 만들고 제거해야 합니다.

화염 파동 렌더러는 개선을 위한 비활성 코드로 남아 있으므로 elemental fixture에서만 직접 검사할 수 있습니다. 이 성공은 파동이 게임 선택지에 다시 추가됐다는 뜻이 아닙니다.


## 후방 꼬리 반격·강화 보스전 테스트

- 정면/먼 후방에서는 일반 패턴, 가까운 후방에서는 먼저 돌아서지 않고 제자리 꼬리 예고→완만한 가속 휘두르기→대상이 있던 방향으로 마무리. 실제 뒤쪽 부채꼴/적별1회 피해, 8초 재사용 제한.
- Studio 로비의 보스전 버튼과 스킬 미리보기/전투 시작이 겹치지 않는지 확인. 자동4개/Q 검증과 일반/테스트 준비 모드 일치, 테스트→로비→일반 출발 시 강화 초기화.
- 테스트 출발: 자동 마법4개/골렘5단계, 레벨21, Q 고정 성능, 체력150, 일반 몹 없이 드래곤. 일반 출발은1단계/레벨1/생존 구간 유지. 게시 환경에서는 버튼/요청 비활성.
- Server fixture: tests/studio_dragon_rear_tail.luau, tests/studio_boss_test_start.luau 및 갱신한 tests/studio_boss_combat.luau. 실제2인/패드/모바일/공격 시각과 판정의 체감 일치는 별도 확인.


## 몹 카탈로그 / 테스트 보스 체력

- 일반 보스 최대체력2,880, Studio 테스트5,760(협동 배율 별도). 복귀 후 일반전에2배가 누출되지 않는지 확인.
- 로비 몹 미리보기/N:6종 선택·이름/특징, 실전 외형 일치, 정예1.2배/왕관, 대기/이동/공격 시연, 일시정지/드래그/휠/시점 초기화.
- 돌진 예고/이동, 마법탄, 폭발 예고/범위는 피해 없는 시연. 상태/적/XP 변경 없이 모델 전환·닫기 정리. 메뉴 중 전투 시간 정지, 닫고 재개.
- 몹↔스킬↔드래곤 전환 시 하나만 열리고 입력/카메라/로비 복구. 실제 패드/모바일과 게시 환경 비노출은 별도 기기/실행 환경으로 확인.
- Client tests/studio_enemy_preview.luau:6종 템플릿/코드 미포함/실전 모델 일치/정예·이동·특수 시연·정리. Server studio_dragon_rear_tail의 일반/테스트 체력 회귀 포함.

## 무장 정예·전체 몹 외형

- N에서6종의 일반/정예,원본 무기 부착과 걷기/공격/시전,폭탄 도화선,사냥개 발/턱/꼬리와 바닥 높이를 확인합니다.
- studio_enemy_roster(client),studio_enemy_cast_cues(server),기존 studio_enemy_preview/client skeleton/server contact를 실행합니다.
- 모든 종류를 본 뒤 V의 드래곤 메시도 생성되는지 확인합니다. 메모리 실패 시 경고를 확인하고 기본 외형이 보이는지 점검합니다.
- 실전 표시기의 혼합 종류 동시 표시와 정리,65초 이후 정예 장비를 확인합니다. 게시/모바일 대규모 렌더 성능은 별도 검증입니다.

- studio_enemy_live_roster(client)는 실제 LocalScript의 표시기/캐시에서 일반6+정예6을 동시에 확인합니다. fixture가 만든 모델은 로컬 시각용이며 서버 AI/피해 목록에 들어가지 않습니다.

## 개체별 보행

- 같은 종류 여러 마리가 동시에 같은 자세를 취하지 않는지, 좌우 흔들림이 갑작스럽지 않은지 확인합니다.
- 걷다가 정지/공격/빙결될 때 전환과 손의 장비 부착을 확인합니다.
- studio_enemy_motion(client)에서20개 위상,템포/흔들림 범위,20Hz/24Hz 패킷 공백,빙결/정지/안정 시드를 확인합니다. 기존 preview/live roster fixture도 다시 확인합니다.

- 해골 병사의 보행을 정면에서 확인하고, 한쪽으로 상시 기울지 않고 양쪽으로 조금씩 흔들리는지 비교합니다. studio_skeleton_posture(client)로 상체 중심/원본 발 동작/idle을 확인합니다.
