# 변경분 Studio 인수 체크리스트

CI는 문법·패키징·일부 순수 로직만 확인합니다. 다음 결과는 실제 Studio에서 기록합니다.
검사에 사용한 Git 커밋(미커밋이면 그 사실), 설치기, Studio 버전, 기기, 클라이언트 수를 함께 남깁니다.
임시 테스트 값과 객체는 재생 종료로 제거하고 저장할 편집 소스가 원래 값인지 확인합니다.

## 구조 변경의 최소 회귀 검사

- 새 Baseplate의 편집 모드에 설치. 서버 모듈 9개, 클라이언트 모듈 11개와 두 진입점 확인.
- Play: 서버/HUD 시작 메시지, 적 생성, 자동 화염탄·골렘 공격, 오류 없는 Output.
- Q/E 각각 실행. 연속 입력 쿨다운, 대시 종료 후 이동 복구와 벽 충돌 확인.
- 경험치 습득 → 카드 3개 → 선택 → 강화. 혼자 선택하는 동안 전투 정지/재개 확인.
- 얼음·번개를 습득하고 타격과 효과 종료 확인. 시전자 사망 시 얼음창 정리 확인.
- 패배 → 재시작: 적·구슬·투사체·레벨·HUD·타이머 초기화. 중복 HUD/입력 연결 없음.
- 120초 뒤 보스 등장, 남은 일반 적 정리와 경험치, 체력바, 예고 후 공격, 처치 승리 및 90초를 넘어도 전투가 이어짐을 확인. 조기 등장 검증용 BossSpawnAt 속성을 썼다면 제거를 확인.
- 캐릭터 몸을 돌린 뒤 Q 발사: 정면 발사와 화살표 제거 확인. 경험치가 18스터드에서 끌려오고 범위를 벗어나도 따라오는지 확인.
- 필요하면 Server 실행 문맥에서 tests/studio_boss_combat.luau를 실행해 별도 임시 보스 환경의 판정·승패·초기화를 확인.

## 협동 또는 모바일을 바꿀 때

- Studio Server & Clients 최소 2명: 경험치 공유, 한 명 선택 중 다른 사람 전투,
  중간 참가·퇴장, 한 명 사망, 모두 종료 후 재시작.
- 모바일은 기기/에뮬레이터 종류와 해상도를 기록. 이동·카메라·Q/E 버튼·카드 겹침 확인.
- 예상 동시 적/효과 수에서 프레임과 서버 부담 관찰. 실제 측정 없이 성능을 단정하지 않음.

## 결과 형식

```text
대상 커밋/소스:
설치 장소/파일:
환경·클라이언트 수:
실행한 순서:
관찰 결과·Output·화면/영상 경로:
실패/미검증:
다음 조치·담당:
```

코드 작성 / 자동 검사 / 실제 엔진 실행 / 시각·청취 / 사람 플레이를 구별합니다.
시각 변경은 같은 카메라·해상도·상태에서 전후 화면이나 짧은 영상을 남깁니다.

## 드래곤·다양한 적

- 드래곤의 입·날개·다리·꼬리 실루엣과 날개/턱/꼬리 동작을 확인.
- 폭발 원 3→5개, 부채꼴 브레스, 돌진의 예고와 실제 피해 범위를 비교.
- Q의 수직 마법진과 끝이 가늘어지는 불꽃 파동, 수명 종료 후 객체 정리 확인.
- tests/studio_enemies.luau로 몹 종류·마도사 탄환·폭발 예고/회피/빙결·보스 중 생성 중단 확인.

## 로비·장착 마법·신규 주문

- Play 후 로비 표시, 적 0마리/라운드 시간 정지, 카드 해제·변경·정확히 3개 선택.
- 선택 마법만 1단계로 출발, Q/E 유지, 강화 카드에 장착 외 주문이 없는지 확인.
- 메테오의 큰 암석·균열·불꽃 꼬리·낙하 예고·충돌 폭발·반경, 메뉴 중 낙하 정지 확인.
- 검무 3칼날/타격 간격, 서리 근접 발동/빙결/보스 면역, 결계 흡수/파괴/초과 체력 피해 확인.
- 사망→로비→다른 조합 출발. 중복 입력과 잘못된 ID 요청 거절.
- tests/studio_area_spells.luau / tests/studio_lobby.luau는 별도 fixture 검사이며 실제 다중 클라이언트 시험과 구분.
- 실제 2명: 전원 준비·준비 취소·미준비 참가자 이탈·전투 중 참가·전원 종료 후 로비 복귀.

- 로비에서 Q 3종을 바꿔 출발/복귀 유지, 실제 Q·패드 R2·화면 버튼의 동일 발동 확인.
- 메테오 3.2초 낙하, 비전 연검 1단계24개/5단계48개·확대 반경, 서리 응축/다중 충격/결정 확인.
- tests/studio_active_spells.luau로 Q 지연·범위·공중/보스 면역·중복 입력·취소 확인.

## 스킬 갤러리

- 로비 버튼과 전투 버튼/P로 열기, 12개 목록 선택, 실제 이펙트와 오류 확인.
- 1/3/5 단계 연검 파편 24/36/48, 반복/단발/다시 재생, 드래그/휠/시점 초기화.
- 로비에서 열고 닫으면 로비로 복구, 전투 타이머 정지/재개, 카메라·FOV·이동·공격 복구.
- 잘못된 previewSkills 인자와 열린 중 Q 요청 거절, XP/장착 불변, 서버에 SkillPreviewStage 없음.
- 드래곤 보기와 전환 후 서로 하나만 열림, 반복 재개방 후 효과 폴더/입력 연결 중복 없음.
- 실제 패드의 목록 선택/오른쪽 스틱/L1/R1/B와 모바일 화면은 별도 검증.

- 비전 결정 5개가 각각 발사되고 충전되며 가까운 적들을 분산 추적하는 단일 타격, 뇌창 준비→실제 비행→관통/벽 충돌/종료, 추적 마탄의 보스 우선·단일 대상·죽은 대상 재탐색 확인.
- tests/studio_homing_missiles.luau, 변경된 studio_active_spells/studio_area_spells/studio_boss_combat 실행.

- 비전 결정: 움직인 적을 부드럽게 추적하는지, 벽에 막히는지, 단계 변경 시 오라 중복이 없는지, 미리보기와 전투에서 시야를 가리지 않는지 확인.
- 새 Play/출발/미리보기 복귀 시 정상 3인칭 거리와 높이, 이후 마우스/패드 회전·줌 자유 조작 확인.
- 뇌창: 입체 창날/금색 장식/이중 고리/동적 번개/비행 꼬리 확인. 다수 효과 동시 실행에서 성능 확인.

- 천공의 창: 장착/강화/미리보기, 공중 마법진→준비→5개 순차 낙하→좁은 경로 피해/지면 파동/정리, 선택 중 정지, 이동 예측과 재시작 취소 확인.
- 혼합 무리: 첫10초 약13마리, 18초마다 양방향6마리 추가, 상한84 확인. 6종 해금·돌진 예고/방향 고정/대시 회피/빙결 중지, 정예 외형/추가 경험치 확인.
- 늘어난 몹과 다섯 결정/낙하 창 동시 실행의 실제 기기 성능 및 난이도는 별도 사람 플레이로 평가.

- 비전 결정: 발사 전 둥근 빛5개가 전부 보이고 네모난 면/탄환 날개가 없는지, 발사한 자리의 조명/입자도 사라지는지 확인.
- 로비 Q4개가 패널 안에 들어가는지, 기존 뇌창과 별도 성운창 선택/재입장 유지, 성운창 준비 잔광→가는 창→비행/관통/벽/쿨다운/정리와 미리보기 확인.
