# 개발 중 플레이 점검 기록

## 2026-10-16 모듈 분리 검증

단일 서버·클라이언트 코드를 서버 7개, 클라이언트 5개 ModuleScript로 분리했습니다.
새 진입점과 함께 설치되며 기존 플레이 수치를 유지했습니다.

- 로컬 Luau 0.742에서 소스·설치기 16개 문법 컴파일 통과.
- 예상하지 않은 전역 참조 검사 통과. 이 과정에서 Effects의 Players 의존성 누락을 수정.
- Python 설치기 검사 5개 통과: 전체 모듈 포함/설치 순서, 문자열 구분자 충돌,
  모듈/폴더 이름 충돌, 빈 모듈 경로, 생성 결과 일치.
- Luau 순수 로직 시험 통과: 레벨업·카드 생성, 잘못된 선택과 중복 선택 거절,
  체력 강화, 종료 상태의 강화 거절. Roblox 엔진을 모의 재현한 시험은 아님.
- 설치기 컴파일에서 함수 호출 뒤 익명 함수 시작의 모호한 구문을 발견해 구분자를 추가.
- **실제 Studio 실행·시각·협동 검증은 미완료.** 연결된 이름 없는 Studio는 `Place is not open`을
  반환했고 별도 FPS place는 수정하지 않았습니다. Studio UI 연결도 시간 초과했습니다.
  아래 이전 기록은 모듈 분리 전 버전의 검증이며 새 버전의 실행 증거가 아닙니다.

## 검증 범위

Studio 솔로 플레이에서 적 생성, 자동 공격, 경험치 수집, 레벨업 카드, 얼음 마법 습득, 충격파 입력, 패배와 재시작을 확인했습니다. 승리 처리는 임시 6초 설정으로 확인하고 최종 설정은 180초로 복구했습니다.

협동용 서버 처리와 경험치 공유의 기반은 포함되어 있으나 여러 클라이언트를 이용한 협동과 모바일 기기 테스트는 아직 진행하지 않았습니다. 소환수 진화, 드래곤, 보스, 장기 저장은 이후 구현 범위입니다.

카메라 변경 후 기본 카메라 회전 입력과 휠 확대·축소를 확인했습니다. 골렘은 플레이어가 거의 정지한 상태에서 독립적으로 이동하는 것을 확인했고, 복귀 테스트에서는 플레이어와의 거리가 약 60에서 39로 감소했습니다. 테스트 중 사용한 자동 선택 연결은 제거했고 임시 위치 변경은 플레이 종료로 초기화했습니다.

땅찍기 변경 후 준비·타격·회복 단계와 팔의 상승·하강을 확인했습니다. 강화 검증용 임시 5레벨 플레이에서 골렘 위치와 충격파 발생 위치의 차이는 0이었고, 대지 강타 두 번과 바위 파편을 확인했습니다. 기본 내려찍기도 별도 효과와 타격 동작으로 발생했습니다. 최종 서버 설정은 골렘 1레벨, 일반 적 체력과 원래 생성 거리, 180초 생존으로 복구했습니다.

자동 강타 변경 후 밀집한 적을 생성한 임시 플레이에서 Q 입력 없이 골렘의 대지 강타가 발생하는 것을 확인했습니다. 화염 파동 검증에서는 연속 요청에도 한 번만 발사되었으며, 정면 적 6마리에게 피해를 주고 뒤쪽 적은 맞히지 않았습니다. 테스트용 적 체력·생성 위치·플레이어 체력 설정은 최종 소스에서 원래대로 복구했습니다.

대지 강타의 손 준비 빛, 타격 섬광, 두 겹 충격파, 먼지와 바위 효과를 추가했습니다. 공개 에셋의 출처·이용 조건·로드 확인 결과는 `ASSET_CREDITS.md`에 기록했습니다. 사용한 바위 메시 템플릿은 Studio 프로젝트의 `ReplicatedStorage.SummonerVFXAssets`에 저장됩니다. 복구 설치기는 공개 모델 로드를 시도하며 실패해도 기본 파편과 먼지 효과로 플레이할 수 있습니다.

화염·빙결·번개 개선 검증: 내장 불꽃 및 불씨 텍스처가 로드되었고, Q 사용 시 9개의 파동 방출기가 생성된 뒤 2초 후 화염 파동 객체와 지면 잔상이 모두 정리되었습니다. 빙결 상태에서 적 이동량과 플레이어가 받은 접촉 피해는 모두 0이었습니다. 세 주문의 화면 표시도 확인했습니다. 검증용 시작 마법·높인 체력·단일 적 생성 설정과 시각 점검용 카메라·정지 프레임은 제거했습니다.

추가 시각 개선: 화염 파동에 초승달 형태의 선두·흰빛 중심·금빛 시전 고리를 추가했고, 얼음창은 대칭 결정과 양옆 작은 결정으로 구성했습니다. 빙결 충격에는 서리 고리·차가운 안개·청록/청색 파편을 겹쳤고 번개는 흰 중심·청록 줄기·보라색 잔광의 세 겹으로 변경했습니다. 클라이언트에 약한 Bloom 효과를 사용합니다. 새 내장 광원 텍스처가 로드되는 것과 효과 종료 후 객체 정리를 확인했습니다.

대시와 마법형 화염 변경 검증: 연속 요청에서 대시가 한 번만 실행되었고 이동 거리는 약 14.72였습니다. 임시 벽 앞에서는 약 5.95만큼 이동한 뒤 멈췄으며 전장 밖을 향한 대시는 반경 81에서 멈췄습니다. E키와 이동 방향 입력, 종료 후 이동 속도·자동 회전 복구, 잔상 정리를 확인했습니다. 마법형 화염의 화면을 확인하고 빛줄기의 폭과 투명도를 줄여 넓고 불투명한 띠가 되지 않게 조정했습니다. 모든 임시 벽·위치·시각 점검용 카메라·반복 재생은 플레이 종료로 제거했습니다.

골렘 최종 단계 이펙트 미리보기 검증: 골렘 1단계의 자동 대지 강타에서 5단계·반경 16의 시각 효과가 두 번 발생하는 것을 확인했습니다. 연출 전용 두 번째 타격의 추가 피해는 0이었습니다. 검증용 적 생성 위치·체력은 원래대로 복구했습니다.

공중 마법진 얼음창 검증: 세로 마법진의 65개 구성 요소와 폭 1.45의 얼음창, 발사 잔상을 확인했습니다. 준비 시간 전에 피해가 발생하지 않고, 도착 후 피해와 빙결이 발생했습니다. 시전자 사망 후 남은 투사체와 시전 효과는 모두 0개였습니다. 테스트용 시작 마법·적 체력·생성 위치·고정 화면과 정지 프레임은 제거했습니다.

주문 형태 재작업 검증: 실제 효과의 정지 프레임으로 뾰족한 얼음 결정 창날, 두께 있는 초승달 파동, 굵은 지그재그 번개와 가지를 확인했습니다. 단일 적을 대상으로 한 실제 얼음창 타격 6회에서 적은 빙결 상태를 유지하면서 0.2초 후 약 3.46~3.54스터드 밀렸습니다. 테스트 전용 마법·적 체력·생성 위치·카메라와 정지 프레임은 제거했습니다.

불꽃·낙뢰 재작업 검증: 내장 불꽃·불씨 텍스처의 Success 로드와 실제 불길 표시를 확인했습니다. 수직 낙뢰 아래 바닥 높이 0.12에서 48개 전류 구성 요소가 방사형으로 퍼지는 것을 화면에서 확인했습니다. 연쇄 후속 타격의 지면 경로도 실행했고, 2초 후 파동 방출기와 번개는 모두 0개였습니다. 게임 스크립트 실행 오류는 없었으며 임시 반복·정지 프레임·카메라와 HUD 변경은 플레이 종료로 제거했습니다.
